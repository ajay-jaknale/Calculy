# Calculy — Pixel-close responsive build

This build follows the supplied Calculy reference screenshots: warm paper background, serif display type, orange accent, left toolkit on desktop, horizontal tool chips on tablet, calculator/converter cards, workspace history panel, and responsive spacing.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Production

```bash
npm run build
```

Vercel: build command `npm run build`, output directory `dist`.

## AdSense-ready

Ad placeholder components are included so approved Google AdSense responsive units can be inserted later. Keep ads visually separate from controls and follow Google's current policies.
